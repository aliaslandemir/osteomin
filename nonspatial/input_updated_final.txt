Fixed (known) parameters ✅
Osteogenic induction + media handling

u_osteo(t): step at t_osteo (timing fixed by your protocol)
Media refresh interval: Δt_med (fixed by your protocol)

Ascorbic acid pulse model (fixed)
Initial AA after refresh: A0 = 0.284 mM (50 μg/mL)
First-order AA decay in medium (Chepda 2001 midpoint-based):
  k_A ≈ 0.11 h^-1  (half-life ≈ 6 h)

Ascorbic-acid gate (fixed form + fixed K_AC)
AA enters only via the osteogenic rate r_osteo, using:
  g_A(A) = A_eff / (K_AC + A_eff)
Here K_AC is FIXED (not fit).

Dex and MK gates (fixed form; EC50 fixed if you keep them fixed)
  g_D(Dex) = Dex / (DEX_EC50 + Dex)
  g_K(MK4) = MK4 / (MK_EC50 + MK4)

Mineralization activation time gate (fixed)
We model mineralization activation using a Hill function:
  h(t_eff) = t_eff^n / (τ^n + t_eff^n)
with τ = 14 days and n = 4 (both FIXED).

Any other fixed parts
- Cell dynamics / cell trajectory terms
- Any additional protocol-timed switches


Free (unknown) parameters to fit 🎯
Because AA is introduced via r_osteo * g_A(A), AA-specific κ_A terms are NOT included (they would be redundant).

ALP: 4 parameters
  r_basal_P : basal ALP production
  r_osteo_P : osteogenic ALP amplitude (multiplies g_A)
  κ_DP      : Dex modifier on osteogenic ALP
  κ_KP      : MK-4 modifier on osteogenic ALP

Collagen: 4 parameters
  r_basal_C : basal collagen production
  r_osteo_C : osteogenic collagen amplitude (multiplies g_A)
  κ_DC      : Dex modifier on osteogenic collagen
  κ_KC      : MK-4 modifier on osteogenic collagen

Mineral / ARS: 4 parameters
  r_basal_H : basal mineral/ARS signal
  r_osteo_H : osteogenic mineral amplitude (multiplies g_A and the fixed Hill time gate)
  κ_DH      : Dex modifier on osteogenic mineral
  κ_KH      : MK-4 modifier on osteogenic mineral
