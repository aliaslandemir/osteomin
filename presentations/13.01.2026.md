# OsteoMin endpoint → ABM coupling (13.01.2026)

## 1. Objective
- Show how endpoint ALP/collagen/mineral curves are translated into hourly rates.
- Describe how pre-OB vs OB populations consume those rates inside OsteoMin.
- Give a modular, stepwise reference for follow-up work.

## 2. Endpoint models (sources)
### 2.1 ALP (piecewise linear)
- Inputs: day-10 cumulative basal \(P^{\mathrm{basal}}_{10}\) and total osteogenic \(P^{\mathrm{osteo}}_{10}\).
- Induction timing: osteogenic stimulation starts at day 3 (matches experimental switch to AA+β-GP media).
- Steps:
  1. Derive basal hourly rate \(r_b = P^{\mathrm{basal}}_{10}/(24\times 10)\).
  2. Solve for osteogenic rate \(r_o\): \(r_o = (P^{\mathrm{osteo}}_{10}-P^{\mathrm{basal}}_{10})/(24\times (10-3)\times \gamma)\); ensures contribution from day 3 to 10 plus scaling \(\gamma\).
  3. Build hour vector \(t_h\) from 0 to day\_measure (default 10) in steps of \(dt=1\).
  4. Integrate: basal component accumulates every hour; osteogenic component only starts once \(t>3\) days.
  5. Sum components to get cumulative \(P(t)\) matching both endpoints exactly.
- Implementation: `datafitting/alptopi/unifiedalpmodel.py` does the algebra, integration, plotting, and JSON/CSV outputs.

### 2.2 Collagen (AA-modulated MM)
- Model:
  \[
  \frac{dC}{dt} = r_0 + \alpha_j\frac{A(t)}{K_m + A(t)},\qquad
  A(t)=A_0\exp\!\big(-k\cdot\mathrm{mod}(t, \Delta t)\big)
  \]
  for \(t\ge 3\) d; collagen flatlines after day 14.
- Steps:
  1. Define AA pulse: \(A_0\) released at day 3, decays exponentially with rate \(k=\ln(2)/\text{half\_life}\), refreshed every \(\Delta t\) hours (media interval).
     - Protocol defaults (CLI in `unified_matrix_mineral.py`): \(A_0=50.0\ \mu\text{g/mL}\), half-life \(=3.0\) h, media interval \(=48.0\) h, AA start day \(=3\). These mirror the experimental feeding schedule.
     - \(\mathrm{mod}(t, \Delta t)\) is simply “time since last media change”: the remainder of \(t/\Delta t\). It resets to 0 at each feed so the exponential decay restarts every medium exchange.
  2. Calculate saturation \(A/(K_m + A)\) each hour (Michaelis–Menten, ensures bounded response).
  3. Euler-integrate \(C(t)\) hour by hour: add \(r_0\) plus AA-driven term as long as \(t<14\); afterwards \(C\) stays constant at day-14 value.
  4. Outputs: collagen time series, endpoint vs \(K_m\) sweeps, sensitivity plots (Sobol optional).
- Implementation: `datafitting/mineralmodel/unified_matrix_mineral.py`.

### 2.3 Mineral (Hill saturation)
- Trigger when collagen exceeds threshold \(C_{\mathrm{th}}\) (basal day-14 max).
- Steps:
  1. Compute \(t_\times\): the hour when collagen crosses \(C_{\mathrm{th}}\), then set \(t_{\mathrm{start}}=\max(14,t_\times)\).
  2. Mineral build follows Hill function with exponent \(n\) and time constant \(\tau_j\): \(H=\gamma_j \frac{(t-t_{\mathrm{start}})^n}{\tau_j^n+(t-t_{\mathrm{start}})^n}\).
  3. Solve \(\tau_j\) algebraically so \(H(28\,\text{d})\) matches the measured ARS endpoint; \(\gamma_{\text{basal}}=0\) ensures basal cultures stay mineral-negative.
  4. Default Hill exponent selection: `n_vals=[1,2,3,4]` with `n_index=2` → final \(n=3\) unless overridden via `--n_vals`.
  5. Outputs include mineral time courses, sensitivity sweeps, and CSV/NPZ for ABM input.
- Implementation: `datafitting/mineralmodel/unified_matrix_mineral.py`.

## 3. Datafit packaging
1. Run `datafitting/datafitmain.py` with endpoint arguments to generate `datafitting/datafit.npz`.
2. The `.npz` stores hourly curves (`alp_basal`, `alp_osteo`, `collagen_C1/C2`, `mineral_C1/C2`, `time_hours`).
3. `DatafitSchedule.from_path` (`src/datafit.py`) interpolates every curve to integer hours and computes increments:
   \[
   \Delta X_h = X_h - X_{h-1},\quad \Delta X_0 = 0,\quad X\in\{\text{ALP, collagen, mineral}\}.
   \]

## 4. Hourly application inside OsteoMin
1. **Hour loop context:** `OsteoModel.run` (`src/model.py`) calls `ABMManager.step_hour` then `FieldManager.step_hour`.
2. **Mix weights:** inside `FieldManager._apply_datafit` (`src/field_manager.py`):
   \[
   w_{\mathrm{pre}}=\frac{N_{\mathrm{pre}}}{N_{\mathrm{pre}}+N_{\mathrm{ob}}},\quad
   w_{\mathrm{ob}}=1-w_{\mathrm{pre}}.
   \]
3. **Blend increments:** for each quantity \(X\),
   \[
   \Delta X = w_{\mathrm{pre}}\Delta X_{\mathrm{basal}} + w_{\mathrm{ob}}\Delta X_{\mathrm{osteo}}.
   \]
4. **Deposit to fields:**
   - Collagen / HA: added to OB mask if present, otherwise uniform grid update.
   - ALP: `FieldManager.add_alp` updates total ALP scalar.
5. **Tracking:** totals for pre-OB/OB contributions (`*_preob_total`, `*_ob_total`) are incremented for reporting/export.

### Mineral-specific rule (biologically constrained)
- Basal mineral curve is ignored; only osteogenic increments are used.
- Mineral adds only when OBs exist (`N_ob > 0`) and only on OB-occupied grid cells; no uniform fallback.

## 5. Reporting / exports
- Spatial snapshots/grids: `viz.py` exports pre-OB vs OB masks + mineral overlays.
- Timeseries: `save_timeseries_csv`/`xlsx` capture `ald_preob_total`, `collagen_ob_total`, `mineral_preob_total`, etc.
- Nodule detection uses HA grid seeds in `FieldManager.detect_nodules`.

## 6. Nodule detection (where and how)
- Location: `FieldManager.detect_nodules` (`src/field_manager.py`), invoked from `OsteoModel.run` after each day update.
- Inputs: OB mask (cells in `CellState.OSTEOBLAST`) and HA grid.
- Rule:
  1. Slide a square window of size `nodule_window` across the grid.
  2. A window is a nodule if **all** sites are OBs **and** every site has HA > 0.
  3. Adjacent hits are clustered; cluster centers are stored as nodule positions.
- Outputs: daily nodule counts/positions, exported in grids and overlays (`out/grids/nodules_day_XXX.npz`, `out/collagen_ha/...`).

## 7. Stepwise follow-up suggestions
1. Regenerate endpoints with new experimental ALP/ARS values via `datafitting/datafitmain.py` → update `datafitting/datafit.npz`.
2. Inspect `datafit.npz` with `np.load` to verify hourly increments before running the ABM.
3. Run `python main.py --datafit datafitting/datafit.npz` to propagate the new endpoints.
4. Use `out/timeseries.xlsx` and spatial exports to confirm pre-OB/OB contributions align with expectations.
